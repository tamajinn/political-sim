# PROJECT_SPEC — 架空国家・総合政治シミュレーション

原典: ユーザー提供の「全面再設計・開発指示書」(25章構成)。本書はその要約と、現時点の確定事項。

## コンセプト
選挙・政党運営・国会・内閣・経済・外交・世論・政治家AIが、**1つの共通ワールドデータ**を介して相互作用するサンドボックス型政治シミュレーション。勝利/敗北条件なし。

## 確定している要件(抜粋)
- 舞台: 架空の日本(テンプレート)。制度・選挙制度は変更可能で、現実に固定しない
- 操作モード: A=政党操作 / B=国家全体操作。**同一エンジン**で操作範囲だけ変える
- 時間: ハイブリッド(日次のリアルタイム進行 + 日程イベント)。速度可変、重要イベントで自動停止(対象は設定可)
- 難易度: カジュアル/標準/リアル/高難度。AIへの不自然な数値ボーナスは禁止
- AI: 初期はルールベース。判断理由を記録。将来の外部生成AI用に判断処理をインターフェース化
- 世論: 国民集団別・時間差あり
- 地図: 実地理データ(ライセンス・オフライン対応を明確に)。画像貼り付けは不可
- セーブ: 複数スロット、バージョン管理、検証、破損時復旧
- オフライン動作。外部APIに依存しない
- 実装していない機能を実装済みと報告しない / ダミーで完成扱いにしない

## Phase 1 の達成内容と制約
達成: エンジン22テスト合格(時間・速度・自動停止・イベント順序・決定論・セーブ/復旧/破損検出・20年ヘッドレス)。

- 開発環境でnpmレジストリへ接続できず(403)、vitest/vite/React を**インストールしていない**。テストは bun の互換ランナーで実行、型チェックは既存の `tsc` で実施
- Web UIは `bun build` でバンドル成功まで確認。**ブラウザでの動作は未検証**、`vite` での起動も未検証
- 地図は未実装(表のみ)。地理データの取得方法の決定待ち
- 経済・外交・政治家AI・選挙計算は未実装
